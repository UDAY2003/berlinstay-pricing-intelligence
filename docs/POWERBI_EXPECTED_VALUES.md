# Power BI expected values (reference for your dashboard)

Every measure in `docs/POWERBI_GUIDE.md`, recomputed with pandas from the CSVs in `powerbi/`, mirroring each measure's filter context. Use it to check your dashboard: put each measure in a **Card**, then apply the slicers. Generated by `python -m src.powerbi_expected` (and asserted in `tests/test_powerbi_measures.py`). This verifies the logic and the data files; it does not run DAX.

- **Scenario A:** no slicers.
- **Scenario B:** slicers `room_type = Entire home/apt` and `district = Mitte`.
- Percent measures are shown as fractions (format as % in Power BI). `Reviews*` use the month axis (Jul 2026 / Aug 2025-Jul 2026).
